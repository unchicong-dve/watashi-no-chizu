わたしの地図 | PWA配布版 Ver.0.4.0

【重要】このZIPは公開前のファイル一式です。URLはまだ発行されていません。

■ 公開手順（GitHub Pagesを利用する例）
1. GitHubにログインし、新しいPublicリポジトリを作成します。
2. このZIPを展開し、index.html / sw.js / manifest.webmanifest / iconsフォルダをリポジトリの最上位にアップロードします。
3. リポジトリの Settings → Pages → Build and deployment で Deploy from a branch を選び、main / (root) を指定して保存します。
4. 公開完了後に表示される https://...github.io/.../ のURLを開いてください。
5. iPhoneでSafariからそのURLを開き、共有 → ホーム画面に追加 → 追加。
6. アプリを一度オンラインで開いてから、機内モードでも開けるかテストしてください。
7. 知人には同じURLと「Safariで開き、ホーム画面に追加」の案内を送ってください。

■ 注意
- GitHub Pagesではアプリのコードは公開されます。自分史の記録は含まれていません。
- 記録は各端末のブラウザ/ホーム画面アプリの保存領域に保持され、サーバーに自動送信されません。
- アプリを削除したり、端末の保存データが消去されると記録が失われる可能性があります。
- 「データ管理」→「記録をバックアップ」で定期的にファイルを保存してください。
- iPhoneのホーム画面版とXcode試験版の記録は自動同期されません。
- 配布前に、実機で記録の保存、再起動後の保持、バックアップ/復元、オフライン動作、PDF出力を確認してください。
- 初回の読み込みにはインターネット接続が必要です。
- GitHub Pagesは公開サイトです。URLを知る人だけに限定する仕組みではありません。
- この配布版はXcodeアプリのインストールファイルではありません。
